# The Vacuum's Alibi: One Line, 200 Characters

An entry for the [make.fun competition "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## What it does

`main.py` (Python standard library only) writes one original line — a robot vacuum's deadpan excuse for missing a spot — to `/output/entry.txt`. The line is 128 characters, one line, UTF-8, with a single trailing newline.

> Battery at 12%, schedule says dock by six, and that crumb has survived three passes — at this point it's a roommate, not debris.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: repeated runs produce byte-identical files (sha256 `7c612c6a817a1931cee0c90a254b9c7d22482a6dc996a393c4efc9c26cb5222b`), and the output file is chmod 0644.
